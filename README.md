# VedaAI - AI Assessment Creator

An AI-powered assessment creation platform built using Next.js, TypeScript, Tailwind CSS, React Hook Form, and Zod.

## Features

* Modern Dashboard UI
* Create Assignments
* AI Assessment Generation UI
* Form Validation using Zod
* Responsive Design
* Sidebar Navigation
* Clean SaaS-style Interface

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* React Hook Form
* Zod
* Lucide React Icons

## Pages

### Dashboard

* View assignment stats
* Recent assignments
* Quick actions

### Create Assignment

* Assignment title
* Subject
* Due date
* Number of questions
* Total marks
* File upload
* AI instructions

## Installation

Clone the repository:

```bash
git clone https://github.com/shrutikumari93/vedaai-assessment-creator.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Deployment

Deployed using Vercel.
